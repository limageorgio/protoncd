## 🆘 Problemas Comuns

### "Não apareço no Google"
→ Aguarde 1-2 semanas após configurar Search Console  
→ Solicite indexação manual das URLs  
→ Verifique se robots.txt não está bloqueando

### "Google Meu Negócio não verifica"
→ Aguarde carta com código (10-14 dias)  
→ Verifique endereço correto  
→ Tente verificação por telefone

### "Palavras-chave não rankeiam"
→ SEO leva tempo (3-6 meses)  
→ Verifique concorrência das palavras  
→ Crie mais conteúdo relevante

### "Tráfego não aumenta"
→ Analise Search Console (impressões vs cliques)  
→ Melhore meta descriptions  
→ Crie mais posts no GMB
