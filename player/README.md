# Pasta Player - Arquivos Públicos

Esta pasta contém arquivos que podem ser acessados diretamente através de links públicos.

## Como usar

1. Faça upload dos seus arquivos (HTML, vídeos, PDFs, etc.) para esta pasta
2. Os arquivos estarão acessíveis através da URL: `www.protoncd.com.br/player/nome-do-arquivo.html`

## Exemplos de URLs

- `www.protoncd.com.br/player/player-elevador-1-player-3.html`
- `www.protoncd.com.br/player/video-demonstracao.mp4`
- `www.protoncd.com.br/player/apresentacao.pdf`

## Observações

- Todos os arquivos nesta pasta são públicos e acessíveis por qualquer pessoa que tenha o link
- Não coloque informações confidenciais ou sensíveis nesta pasta
- Os arquivos são servidos diretamente sem restrições de acesso
